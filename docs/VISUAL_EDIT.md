# 렌더 전 시각 편집과 검토

`grid-review`의 watch trim 뒤, 스타일 구성과 최종 렌더 앞에서 실행한다.

- `--visual-edit off`: 기본값. 새 시각 편집 단계는 실행하지 않는다.
- `--visual-edit preview`: 검사·가능한 수정 후 `shorts_vN_visual_preview.mp4`를 만든다. 기존 완성본을 덮어쓰지 않으며 발행 메타데이터를 만들지 않는다.
- `--visual-edit strict`: 동일 검사 후 미해결 항목이 하나라도 있으면 최종 렌더 전에 실패한다. 렌더 후 발견된 얼굴 가장자리 경고도 검토 목록에 추가하고 최종 파일 내보내기를 막는다. 이 옵션은 로컬 생성 게이트이며 외부 발행 시스템에 별도 승인 UI를 추가하지 않는다.

## 시각적 노이즈를 찾는 기준

원본 fps를 유지한 FFmpeg scene 변화(`0.22`)에서 경계를 찾고, 실제 출력 프레임 시계로 변환한다. 0.4초 미만의 독립 샷을 검토 후보로 삼는다. 화자가 같은지 여부와 무관하다. 같은 원본 샷이 연속된 기술적 클립 분할은 하나로 합쳐 센다. 임계는 휴리스틱이며 움직임을 컷으로 오인하거나 약한 전환을 놓칠 수 있다.

후보 버전 14개가 같은 소스를 쓰면 `visual_sources/<source fingerprint>/<10초 tile>.json`을 공유한다. 선택 구간에 필요한 타일만 분석하고, 후보별로 관련 샷 ID·출력 프레임·원본 구간을 짧게 저장한다. 전체 원본 분석표를 매번 모델 프롬프트로 보내지 않는다.

## 자동 수정 범위

내레이션 덮개에서는 앞뒤 및 내부의 짧은 샷을 덜고, 이미 선택된 나머지 영상으로 같은 내레이션 비트의 출력 프레임 수를 채운다. 1~1.2배속, 정지·감속 없음. 필요하면 승인된 span 안의 같은 샷에서 최대 0.4초를 빌리되 다른 사용 구간·제외 구간과 겹치지 않는다. 충분한 화면이 없으면 비트 전체를 원래대로 남긴다. 증거로 지정된 span에 걸친 삭제도 보류한다.

**원음 구간은 자막 공백만으로 삭제하지 않는다.** 전사에 빠진 짧은 말까지 보존하기 위해 현재 생성 경로는 원음의 짧은 샷을 검토 대상으로 남긴다. 내부 함수는 별도로 검증된 무음 구간을 받으면 프레임 단위 삭제와 자막/TTS 재매핑을 지원하지만, 현재 생성 경로는 이 입력을 제공하지 않는다.

내레이션 덮개와 자료 화면은 문맥에 맞는 한 대상/핵심 정보를 크게 잡는다. 전체 가로 축소 fit은 자동 대안에서 제외한다. 불가능한 구도는 기존 채움 크롭으로 미리보기하고 검토 대상으로 남긴다. 수동 `reframe`은 유지한다.

## 검토 목록에 남으면

`review_vN/visual_review.md`와 `visual_edit.json`에 출력 시간·사유·검토 ID를 기록한다. 미리보기는 볼 수 있지만 strict 최종 출력은 막힌다. 목록에 기록됐다는 사실만으로 수정 완료나 승인으로 처리하지 않는다.

수정 후 다시 실행하거나, 사람이 보고 그대로 쓰기로 결정한 항목만 같은 폴더의 `visual_review_decisions.json`에 기록한다:

```json
{
  "source_identity": "visual_edit.json의 source_identity",
  "decisions": [{"id": "review_items의 id", "action": "keep", "reason": "확인한 이유"}]
}
```

원본·출력 시간·대상·문제가 달라지면 이전 승인은 적용되지 않는다. keep은 대사나 화면을 삭제하는 동작이 아니라 해당 상태를 사람이 수용했다는 기록이다. 대시보드 버튼·알림·작업 큐 연결은 아직 없다.

## 검증 범위

테스트는 내레이션 프레임 수/음성 보존, 원음 보호, 정보 화면의 fit 금지, 수동 구도 우선, 캐시 공유, strict 차단, 별도 미리보기 경로와 변경된 항목에 대한 과거 승인 무효화를 확인한다. 영상 모델의 인물 식별이나 모든 프레임에서의 정확성은 보장하지 않는다.
