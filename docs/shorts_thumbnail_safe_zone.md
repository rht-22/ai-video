# 유튜브 쇼츠 썸네일 안전 구역 (2026-09-07 실측)

캔버스 1080×1920 기준. 쇼츠 피드/채널 탭의 썸네일은 세로 전체를 보여주지 않고
**위·아래를 잘라** 보여준다. 가왕쇼 7화 안대 편(0477d230) 썸네일 스크린샷과 완성본
프레임을 맞대어 잰 값이다.

| 구역 | 캔버스 y | 비고 |
|---|---|---|
| 위 잘림 | 0 ~ **약 140** | 제목 윗변이 이 아래에 있어야 한다 |
| 보이는 창 | **140 ~ 1740** | 높이 1600 |
| 아래 잘림 | **약 1740** ~ 1920 | 캡션(로고 아래 문구)이 걸린 자리 |

- 실사고: 캡션 1744~1782 가 절반 잘려 나왔다(썸네일에서 "티빙에서 풀버전 시청 및 투표 가능!"
  윗부분만 보임). 로고 1448~1707 은 전부 보였다.
- 여유를 두면 **제목 윗변 ≥ 180 · 마지막 요소 아랫변 ≤ 1700** 을 권장한다(측정 오차 ±20px +
  둥근 모서리).
- ⚠ 쇼츠 **재생 화면**은 별개다 — 하단에 제목·채널명·설명 오버레이가 더 넓게(대략 아래 300px+)
  덮이고 오른쪽에 좋아요·댓글 버튼 열이 있다. 썸네일 안전 구역에 들어도 재생 중엔 캡션이
  오버레이 밑에 깔릴 수 있다. 재생 화면 실측은 아직 없다.

## 2026-09-11 재측정 · 엔진 자동 맞춤

- 지금불륜 2화 2편·가왕쇼 네 편 썸네일 스크린샷을 완성본 **밴드 경계**(24:23 443~1477 ·
  13:9 420~1168)에 맞대어 다시 쟀다 — 두 장 모두 보이는 창 **약 148~1770**. 1080 폭을 카드 폭에
  맞춘 **2:3 가운데 크롭**(150~1770)과 일치한다. 위 표의 140~1740 보다 아래쪽이 30px 더 보인다.
- 지금불륜은 작품 로고가 밴드 아래 남은 공간 **가운데**(1565~1831)에 앉아 둘째 줄이 잘렸다.
- 사용자 기준: "가왕쇼 … 맨 위와 맨 아래 경계 자체는 참고할 만 해"(가왕쇼 제목 블록 윗변 187 ·
  캡션 블록 아랫변 1711).
- **v3 는 렌더 직전 자동으로 맞춘다** — `finalize.fit_thumbnail_safe_zone`. 경계는 **블록 기준**
  (제목 drawtext y · 하단 블록 = 플랫폼 줄·작품명/로고·캡션 줄 높이 포함) `THUMB_SAFE_TOP 180` ·
  `THUMB_SAFE_BOTTOM 1715`. 글자 픽셀은 블록보다 10px 안팎 안쪽이다.
  - 제목은 이 편의 실제 크기가 아니라 **채널 상한(title_sizes)** 으로 잰다 — 편마다 제목 길이가 달라도
    밴드·로고 자리가 같아야 채널 격자가 가지런하다.
  - 순서: ① 로고 가운데 정렬 해제(밴드 +20 에 붙임) ② 반대쪽 여유만큼 밴드 이동 ③ 로고 축소(하한 0.7)
    ④ 제목 상한 축소(하한 0.8) → 그래도 밖이면 `[v3/썸네일] ⚠` + run_log `thumb_safe.unmet`(렌더는 계속).
  - 결과: 지금불륜 = 밴드 443→434 · 로고 620×194 → 486×154 · 하단 1831→1714 · 제목 윗변(상한 기준) 180.
    가왕쇼 = 밴드 420→424 · 제목 상한 92/112 → 87/106(짧은 제목이 상한 크기로 커지면 166 까지 올라가
    잘리던 자리 — 긴 제목 편은 줄 크기가 원래 상한 아래라 거의 안 바뀐다).
  - 밴드를 옮기면 Stage 4 라벨(캔버스 좌표)도 같은 px 만큼 옮긴다.
- v1(E 계열) 렌더는 이 맞춤이 없다.

## 가왕쇼 템플릿(`app/data/channel_designs/gawangsho.json`)이 지키는 방법

모든 요소가 영상 밴드 기준이라 `video_y` 하나로 같이 움직인다.

| 요소 | video_y 500 (기존 두 편) | video_y 420 (템플릿) |
|---|---|---|
| 제목 | 267 ~ 474 | 187 ~ 394 |
| 영상 밴드(13:9) | 500 ~ 1246 | 420 ~ 1166 |
| 대사 자막(1줄) | 1292 ~ 1340 | 1212 ~ 1260 |
| 로고 | 1448 ~ 1707 | 1365 ~ 1627 |
| 캡션 | 1744 ~ 1782 ✗ | 1664 ~ 1702 ✓ |

- 제목 위 여백 47px · 캡션 아래 여백 38px. 더 올리면 제목이 먼저 잘린다 — 80px 이 균형점.
- 로고가 밴드를 따라오려면 `work_band_offset` 을 쓰고 **`work_title_y` 를 주지 않는다**
  (절대 하한이 밴드 상대 배치를 막는다 — renderer 가 offset 이 있으면 무시하도록 고쳤다).
- 새 채널 템플릿을 만들 때 확인 절차: 완성본 프레임에서 밝은 행 구간을 재고(`tests` 가 아니라
  아래 한 줄) 위 표에 넣어 본다.

```bash
ffmpeg -v error -y -ss 30 -i final_1080x1920.mp4 -frames:v 1 frame.png
```
