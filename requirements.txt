# 2026-08-18 실측: YouTube 소스 5개 채널이 한 시간 사이에 전부

# 받다가 **항상 5.3% 부근에서 403** — 쿠키·조각 크기(1M/10M/1G)·dashy·PO 토큰(bgutil)·

# 그대로 완주했다(mm-05 실측: 184.85MiB 전량, default 10초 / visionos 7초).
#
# 이 싸움은 며칠 단위로 뒤집힌다. '>=' 로 두면 안 되는 이유가 둘이다.
#   · pip install -r 은 조건을 이미 만족하면 업그레이드하지 않는다(updater._pip_sync).
#     하한만 올리면 6대가 서로 다른 나이틀리를 쓰게 되고 "어떤 맥에서만 죽는다"가 된다.
#   · 반대로 검증 안 된 최신 나이틀리가 조용히 들어오는 것도 위험하다.
# **실측으로 통과를 확인한 빌드만 핀으로 올린다.** 유튜브가 또 막으면 여기부터 본다.
